Is the training working?

    How this is judged: the robot makes the same 20 test trips (never used for training) with the trained model and with the untrained model, both given the same examples. It counts as progress only if the trained model is faster on most trips and the gain is bigger than the trip-to-trip noise (95% likely range above zero). The page updates itself every 30 s.

    How the regression works

    TabPFN is a regressor: given a goal (distance to b, bearing to b as sine and cosine, horizon in cycles) it predicts the command, one model per output. Start weights are the weights the round began from (TabPFN's original weights in round 0, the previous round's weights after that). Points on the dashed y = x line are perfect predictions.
