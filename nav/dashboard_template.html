Does TabPFN walk the robot from a to b?

    How this is judged: every controller walks the same 20 held-out a→b trips (never used as examples), with a 40 s limit per trip and a 0.1 m success circle around b. The best controller is the one with the straightest paths (highest mean directness). The hand-written baseline walks the same trips. A difference counts only when the trip-by-trip 95% likely range excludes zero.

    Controllers

    A controller is a set of recorded examples handed to TabPFN's built-in fit(); at every 1 s gait cycle the robot calls predict(). No weights are trained. Goal controllers map the goal (distance, bearing, horizon) straight to a command (stride, turn). Planner controllers predict the body motion of 45 candidate commands and pick the one that gets closest to b. Prediction quality is measured on held-out examples; the evaluation columns come from each controller's latest 20 test trips. Best first, by directness.

    Comparison

    Each bar is one controller's latest evaluation; the dashed line is the hand-written baseline on the same trips. Directness is the straight-line distance divided by the path walked (1 = perfectly straight; a trip that did not reach b counts as 0).
